# Lista de Contatos

Sistema de gerenciamento e consulta de contatos desenvolvido com PHP e MySQL. O projeto permite cadastrar, armazenar, listar, pesquisar e visualizar informações de contatos através de uma aplicação web.

## 🎯 Objetivo

Desenvolver uma aplicação web para centralizar informações de contatos, aplicando conceitos de desenvolvimento backend, integração com banco de dados e operações CRUD.

## ⚙️ Funcionalidades

- [x] Conexão com banco de dados MySQL utilizando PDO.
- [x] Cadastro e armazenamento de contatos.
- [x] Listagem dos contatos cadastrados.
- [x] Pesquisa por nome e endereço de e-mail.
- [x] Visualização individual dos contatos.
- [x] Validação dos dados recebidos.
- [ ] Melhorias na interface e experiência do usuário.

## 🛠️ Tecnologias utilizadas

- JavaScript
- PHP
- MySQL
- PDO
