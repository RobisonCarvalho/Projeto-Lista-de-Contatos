# Lista de Contatos

Sistema de gerenciamento e consulta de contatos desenvolvido com PHP e MySQL. O projeto tem como objetivo armazenar, organizar e consultar informações recebidas por meio de formulários, servindo como base para futuras funcionalidades administrativas.

## 🎯 Objetivo

Desenvolver uma aplicação web que permita centralizar informações de contatos, facilitando o armazenamento, a consulta e a organização dos dados.

## ⚙️ Funcionalidades previstas

- [x] Conexão com banco de dados MySQL.
- [ ] Cadastro e armazenamento de contatos.
- [ ] Listagem dos contatos cadastrados.
- [ ] Pesquisa por nome e e-mail.
- [ ] Visualização individual dos contatos.
- [ ] Validação dos dados recebidos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO
